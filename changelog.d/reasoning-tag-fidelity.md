- **Reasoning-tag cleanup is an explicit route policy and preserves incomplete literal tags.** The validated `reasoningTagPolicy` values are `preserve`, `legacy-inline`, and `hy4-nonce`; unknown routes preserve literal XML and quoted tags by default. Only the captured Qwen Plan Flash route retains automatic bare-tag cleanup, while Hy4's established nonce handling leaves bare tags intact unless explicitly opted in. An explicit `preserve` overrides either default.
